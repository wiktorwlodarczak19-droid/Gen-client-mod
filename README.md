# GEN CLIENT

Customowy client-side mod do Minecraft **1.21.1** na **Fabric**.

## Wymagania
- Java 21
- Minecraft 1.21.1
- Fabric Loader i Fabric API

## Budowanie
Uruchom `gradle build`. Gotowy JAR znajdziesz w `build/libs/`.

## Sterowanie
- **Prawy Shift** — otwiera panel GEN CLIENT.

## Status
Pierwszy fundament projektu: konfiguracja Fabric/Gradle, skrót klawiszowy i bazowy panel Visuals. Przełączniki są na razie szkieletem UI — kolejne etapy podłączą je do rzeczywistych efektów renderowania i konfiguracji.
